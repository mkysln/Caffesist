# Caffesist

Caffesist is an Android application built with Kotlin and Jetpack Compose. It provides account registration and sign-in, a browsable menu, a basket and order flow, camera-based scanning, and order history.

## Features

- Firebase Authentication for account access
- Menu browsing and item details
- Basket and order flow
- Camera and ML Kit barcode scanning
- Order history
- Jetpack Compose navigation and Material 3 UI

## Requirements

- Android Studio with the Android SDK
- JDK compatible with the project’s Gradle configuration
- Firebase project configuration

## Setup

1. Clone the repository and open it in Android Studio.
2. Configure the Firebase Android app and add the required `google-services.json` to the app module.
3. Sync Gradle and run the app on an Android device or emulator.

The app targets Android API 34 and requires Android 10 (API 29) or later.
