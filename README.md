# Caffesist

Caffesist, kafe sipariş sürecini dijitalleştirmek amacıyla geliştirilen bir Android uygulamasıdır. Kullanıcıların menüdeki ürünleri incelemesi, seçimlerini sepete eklemesi ve sipariş akışını takip etmesi hedeflenir.

Uygulama ayrıca kullanıcı hesabı ve sipariş geçmişi gibi işlevleri bir araya getirir. Kamera ve barkod tanıma desteği, ürünlerle etkileşimi kolaylaştıran uygulama parçalarındandır.
